# Conecta Comércio — Design do sistema

Site de apresentação do design de interface do **Conecta Comércio** (TCC): identidade visual e telas da associação, do lojista e do aplicativo do consumidor.

## Como abrir

Abra o arquivo `index.html` no navegador, ou sirva a pasta localmente:

```bash
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Estrutura

```
SITE-APRESENTACAO/
├── index.html
├── README.md
└── imagens/
    ├── asset/       # logo e assets de marca
    ├── associacao/  # design web da associação
    ├── lojista/     # design web do lojista
    └── mobile/      # design do app do consumidor
```
